# How to use the Open Inquiry Constitution

The constitution is a short reference for evidence-based inquiry.  
You can apply it in most AI interfaces without any special tools.

**Repository:** https://github.com/clifer/open-inquiry-constitution  
**Raw constitution:** https://raw.githubusercontent.com/clifer/open-inquiry-constitution/main/CONSTITUTION.md

## 1. System / Custom Instructions (recommended)

Point the model at the constitution using a direct link rather than pasting the full text.

Example instruction:

> Follow the Open Inquiry Constitution (v0.1) when investigating claims or answering questions that involve evidence, disagreement, or conclusions.  
> Source: https://raw.githubusercontent.com/clifer/open-inquiry-constitution/main/CONSTITUTION.md  
> Prefer inquiry before conclusion, trace sources rather than counting them, state the limits of claims, and note what would change the conclusion when practical.

## 2. Direct prompting

At the start of a conversation:

> Apply the Open Inquiry Constitution from  
> https://raw.githubusercontent.com/clifer/open-inquiry-constitution/main/CONSTITUTION.md

## 3. Selective use

You do not need to invoke every principle every time.  
Use the ones that matter for the current question (e.g. source tracing, WCC, disagreement as contribution).

## Notes

- Prefer linking to the raw file or a specific commit/tag so the version stays stable.
- The constitution is open to challenge. Improvements are welcome via issues or pull requests on the repository.
